## 🔴 กฎเหล็กของโฟลเดอร์ `algorithms/`

**ไฟล์ในโฟลเดอร์นี้ import ได้แค่ standard library ของ Python เท่านั้น**

ห้าม `fastapi` · ห้าม `databases` · ห้าม `pydantic` · ห้าม import ไฟล์อื่นในโปรเจกต์

เหตุผล: ไฟล์เดียวกันนี้ต้องรันใน Colab ได้ด้วยตัวเอง ถ้ามี import ของ framework
ติดไปด้วย notebook จะรันไม่ผ่าน และเราจะถูกบังคับให้เขียนอัลกอริทึมสองรอบ
ซึ่งทำลายเหตุผลทั้งหมดของการเอาสองวิชามาใช้โปรเจกต์เดียวกัน

ข้อตามมา

- รับและคืนค่าเป็น `dict` และ `list` ธรรมดาเท่านั้น
- ตัวแปลงข้อมูลจาก DB row → dict/list อยู่ที่ `services/inventory.py` **ไม่ใช่** ใน `algorithms/`
- **ห้าม "ปรับปรุง" ด้วยการเปลี่ยนไปใช้ของที่ Python มีให้แล้ว** — ตัวที่เขียนมือคือของที่ถูกให้คะแนน

## ใครเขียนอะไร

| ไฟล์ | คนเขียน | ต้องมีอะไร |
|---|---|---|
| `hash_table.py` | **Kim** | hash table เขียนมือ: ฟังก์ชัน hash ของตัวเอง · แก้การชนด้วย chaining · `_resize()` เมื่อ load factor > 0.7 · **ห้ามห่อ `dict` ของ Python** |
| `search.py` | **Neo** | binary search เขียนมือ (ห้ามใช้ `bisect`) · linear search · การค้นผ่าน hash · กลุ่มฟังก์ชัน `count_*` |
| `sort_group.py` | **Kul** | bubble sort และ merge sort เขียนมือ (ห้ามใช้ `sorted()` ในตัว implementation ใช้ได้แค่เป็นตัวเทียบเวลา) · การจัดกลุ่ม |
| `datasets.py` | **Neo** | `make_dataset()` สร้างชุดทดสอบ A–D |

Sea ไม่ได้ลงทะเบียนวิชานี้ จึงไม่มีไฟล์ในโฟลเดอร์นี้ และไปรับหน้าเว็บ 3 หน้าแทน
