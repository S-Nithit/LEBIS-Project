## ใครเขียนอะไร

| ไฟล์ | คนเขียน | ต้องมีอะไร |
|---|---|---|
| `hash_table.py` | **Kim** | hash table เขียนมือ: ฟังก์ชัน hash ของตัวเอง · แก้การชนด้วย chaining · `_resize()` เมื่อ load factor > 0.7 · **ห้ามห่อ `dict` ของ Python** |
| `search.py` | **Neo** | binary search เขียนมือ (ห้ามใช้ `bisect`) · linear search · การค้นผ่าน hash · กลุ่มฟังก์ชัน `count_*` |
| `sort_group.py` | **Kul** | bubble sort และ merge sort เขียนมือ (ห้ามใช้ `sorted()` ในตัว implementation ใช้ได้แค่เป็นตัวเทียบเวลา) · การจัดกลุ่ม |
| `datasets.py` | **Neo** | `make_dataset()` สร้างชุดทดสอบ A–D |

Sea ไม่ได้ลงทะเบียนวิชานี้ จึงไม่มีไฟล์ในโฟลเดอร์นี้ และไปรับหน้าเว็บ 3 หน้าแทน

### ชุดข้อมูลทดสอบ

| ชุด | ข้อมูล | ใช้ทดสอบอะไร |
|---|---|---|
| A | 10 รายการ สะอาด | ผลลัพธ์ปกติ |
| B | 12 รายการ มีชื่อซ้ำ | การจัดการค่าซ้ำ |
| C | 10 รายการ ของหมดสต็อก | ค่าขอบ (ศูนย์) |
| D | 120 รายการ | เปรียบเทียบเวลาทำงานจริงกับ Big-O |

### 🔴 ทุกคนต้องวัดผลบนชุด A ถึง D เป็นหลัก

ตัวเลขในรายงานของทั้งสามคน (`hash_table.py` · `search.py` · `sort_group.py`)
**ต้องมีผลบนชุด A, B, C, D ครบทั้งสี่ชุด** จาก `make_dataset()` ตัวเดียวกัน

ใครจะเพิ่มชุดของตัวเองต่อท้ายก็ได้ (เช่น Kim มีชุด 1,000 กับ 4,000 รายการ
ไว้ให้เห็นเส้นโค้งของ O(n) เทียบ O(1) ชัดขึ้น เพราะชุด D ใหญ่สุดแค่ 120 รายการ
ซึ่งยังน้อยเกินกว่าจะเห็นความต่างชัด) แต่ชุดเสริมต้องอยู่**ต่อท้าย**
ไม่ใช่มาแทนชุด A-D

เหตุผล: รายงานสามหัวข้อจะเทียบกันได้เฉพาะเมื่อวัดบนข้อมูลชุดเดียวกัน
ถ้าแต่ละคนวัดบนข้อมูลของตัวเอง ตัวเลขจะอ่านเทียบกันไม่ได้เลย
และกรรมการจะเห็นทันทีว่าสามหัวข้อไม่ได้คุยกัน

**สถานะตอนนี้:** `datasets.py` ยังไม่เสร็จ (งานของ Neo) `hash_table.py`
จึงวัดบนข้อมูลตัวอย่างของตัวเองไปก่อน และมี TODO กำกับไว้ท้ายไฟล์แล้วว่า
ต้องกลับมาเพิ่มรอบวัดผลบนชุด A-D — ใครเขียนอัลกอริทึมเสร็จก่อน `datasets.py`
ให้ทำแบบเดียวกัน คือใส่ TODO ไว้ท้ายไฟล์ อย่าปล่อยให้ลืม

**ข้อควรระวังเวลาเอา `make_dataset()` มาใช้:** ห้าม `import datasets`
ในไฟล์อัลกอริทึม เพราะผิดกฎ stdlib เท่านั้นด้านบน วิธีที่ถูกคือ
ใน Colab วางเซลล์ของ `datasets.py` ไว้ก่อน แล้วส่ง list ที่ได้เข้าฟังก์ชัน
วัดผลตรงๆ ส่วนในโปรเจกต์ให้เขียนสคริปต์วัดผลแยกไว้ข้างนอกโฟลเดอร์ `algorithms/`
